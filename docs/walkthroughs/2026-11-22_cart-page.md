# Cart Page UI & Navigation Wiring

- **Date**: 2026-11-22
- **Summary**: Built the Shopping Cart screen (`CartPage`) with item cards (`CartItemCard`), quantity stepper, item removal, sticky checkout summary bar (`CartCheckoutBar`), animated loading shimmer (`CartShimmer`), empty/error states, and pull-to-refresh. Enriched `CartProductEntity`, `CartResponseDto`, `OrdersMapper`, `CartState`, and `CartCubit` to expose product metadata (`title`, `imageCover`, `brandName`, `categoryName`) and `totalPrice`, added `AppRoutes.cart`, wired navigation from `HomeHeader` and `ProductDetailsPage`, added EN/AR localizations, and added unit and widget tests.

## API Changes
- None. Uses existing `/api/v2/cart` endpoints (`GET`, `POST`, `PUT`, `DELETE`).
- Hardened `Products.fromJson` in `CartResponseDto` to handle both populated `Map<String, dynamic>` product objects (`GET`/`PUT`/`DELETE`) and `String` product IDs (`POST`).

## Widgets
- Feature-specific widgets added under `lib/features/orders/presentation/cart/widgets/`: `CartItemCard`, `CartCheckoutBar`, `CartShimmer`. No new shared primitives in `lib/core/common_ui/` (`docs/04-theme-and-ui-components.md` unchanged).

## DI
- Reuses existing `@singleton CartCubit` registration; no DI annotation changes required.

## Routing
- Added `AppRoutes.cart = '/cart'` in `lib/core/routing/app_routes.dart` and wired `CartPage` in `lib/core/routing/route_gen.dart`.
- Wired cart icon buttons in `HomeHeader` (Home, Categories, Products List) and `ProductDetailsPage` to navigate to `AppRoutes.cart`.
